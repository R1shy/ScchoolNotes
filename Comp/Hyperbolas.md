## Equation
$(\frac{x-h}{r_x})^2\pm(\frac{y-k}{r_y})^2=1$


## Example
```desmos-graph
(\frac{x-3}{2})^2-(\frac{y+4}{5})^2=1
```


## Notes
slope asymtote = $\pm\frac{r_y}{r_x}$


## Completing the Square
move c to rhs
factor if a  $\gt1$ in either x or y equation
normal complete the square for both
remember that you add factor number + c NOT JUST C
