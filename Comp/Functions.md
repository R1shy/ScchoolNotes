
## Definition
a rule/relationship where each input (x) has exactly one output (y)


## Example
Is a function $(f(x)=x^2)$:

| x   | y   |
| --- | --- |
| 2   | 4   |
| 6   | 8   |
| 8   | 10  |
| 10  | 12  |
Not a function $(y^2=x)$:

| 2x  | y   |
| --- | --- |
| 2   | 4   |
| 2   | 5   |
| 3   | 1   |
