[[ForceOfFriction]]## Notes
Forces parallel to the velocity of an object will cause the object to speed up or slow down
forces perpendicular to the velocity will cause the object to change directions (turn)
an object moving in a circular path is always accelerating even at a constant speed because the direction of the velocity is constantly changing
